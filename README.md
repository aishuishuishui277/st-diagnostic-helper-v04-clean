# ST Diagnostic Helper v0.4 Clean

一个用于 **SillyTavern** 的轻量级诊断助手插件。

主要用途是把酒馆生成过程中的常见排错信息整理成可复制报告，方便社区答疑、接口排错和生成链路判断。

它不是模型增强器，也不是官方调试器。它的目标是让普通用户在不打开 DevTools、不暴露聊天正文和 API Key 的情况下，快速提供一份相对安全、清晰的诊断信息。

---

## 主要功能

### 1. 社区超简报

面向社区发帖和快速答疑。

输出内容非常短，只保留最关键字段：

- 模型
- 预设名称
- 用户填写的上游域名线索
- 生成状态
- HTTP 状态
- 流式观察
- Prompt 总量
- 主要 Prompt 压力来源
- 建议动作
- 隐私说明
